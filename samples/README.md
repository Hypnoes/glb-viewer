## NEON RANGE

Generated by the NEON RANGE project's `tools/asset-export/neon_assets.py` exporter and copied unmodified into `samples/neon/` for preview integration. These are generated build artifacts: they may be regenerated, so do not hand-edit them.

| File | Asset id | Purpose |
| --- | --- | --- |
| `neon/range_arena.glb` | `ENV_RANGE` | Closed training-range blockout; includes an authored interior `view_hint`. |
| `neon/weapon_nr01.glb` | `WPN_NR01` | First-person weapon view-model with a muzzle anchor. |
| `neon/drone_mk2.glb` | `PRP_DRONE_MK2` | Hover-target drone prop. |
| `neon/cover_crate.glb` | `PRP_COVER_CRATE` | Cyan-trim cover crate prop. |
| `neon/drone_mk2.anims.json` | `PRP_DRONE_MK2` | Sidecar animation library for the drone: `spawn`, `idle`, `destroy` (schema 1). |

Each NEON RANGE GLB carries a `NEON RANGE` glTF `extras` block on its root node (`userData.neon_range` in three.js) with `asset_id`, `source`, `units` and an optional authored `view_hint`.
